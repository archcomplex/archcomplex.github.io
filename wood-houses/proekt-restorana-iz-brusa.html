Проект ресторана из бруса

Обсудить похожий проект →

«Проект ресторана из бруса»: ресторан из бруса на каменных опорах: протяжённый объём из нескольких повторяющихся двускатных секций, крытая деревянная галерея-терраса вдоль всего фасада, витражное остекление торцевого фронтона.

Площадь — 650 м². Этажность — 2. Материалы и отделка: натуральный камень, брус, дерево, панорамное остекление. Разработка ведётся по стадиям: архитектурные решения, конструктив с раскладкой бруса, инженерные системы и рабочая документация для строительства.
